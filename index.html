Theory 1 — AES-256

What is AES-256?

AES-256 is the strongest variant of the Advanced Encryption Standard, standardised by NIST in 2001. It uses a 256-bit key and 14 rounds. Used in government, military, banking, and every HTTPS connection worldwide.

Block cipher

128-bit blocks

Data is arranged into a 4×4 grid of bytes called the state matrix. AES transforms this state through 14 rounds of operations.

256-bit key

2²⁵⁶ keys

More possibilities than atoms in the observable universe. Brute force is impossible even for all computers on Earth combined.

14 rounds

Nr = Nk + 6

AES-256 has Nk=8 key words, so rounds = 8+6 = 14. Each round applies 4 different operations with a unique round key.

Symmetric

Same key both ways

The exact same 256-bit key encrypts and decrypts. AES-256 provides 128-bit post-quantum security against Grover's algorithm.

Why 256 bits? AES-128 is already unbreakable today. AES-256 adds an extra 128-bit safety margin specifically to resist future quantum computers (Grover's algorithm halves effective key size: 256 → 128 post-quantum bits).

Theory 4 — Round Structure

AES-256: 14 Rounds — Why and How

Formula: Rounds = Key words + 6 = 8 + 6 = 14. Each round mixes the data further. After just 2 rounds, every output bit already depends on every input bit.

All 14 rounds
Why 14? Rule: Rounds = Key words + 6 = 8+6 = 14. More key bits → more rounds → harder to reverse. Two rounds already create full avalanche (every bit affects every bit).

Apply ShiftRows: rotate Row 1 left by 1 position
ShiftRows rotates each row cyclically left. Row 0 → shift 0 (stays). Row 1 → shift 1 (first element moves to end). Row 2 → shift 2. Row 3 → shift 3.
Row 0 (shift 0): D4 E0 B8 1E → stays same
Row 1 (shift 1): 27 BF B4 41 → after shift: ???
Row 2 (shift 2): 11 98 5D 52
Row 3 (shift 3): AE F1 E5 30

Correct! [27 BF B4 41] shift left 1 = [BF B4 41 27]. The '27' moved from position 0 to position 3. Now MixColumns can blend it with bytes from other original columns.
Not quite. Shift left by 1: [a b c d] → [b c d a]. The first element 'a' wraps to the end. So [27 BF B4 41] → [BF B4 41 27].
